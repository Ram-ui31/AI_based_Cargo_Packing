    Run ARGO on your own instance

    Upload a CSV in the same format as the competition instance (ULDs and packages) and this page will run the real model live, no download required.

    Expected CSV format

    Plain CSV, no header row:

    • Line 1: the K value (spread-cost multiplier) alone, e.g. 5000
    • ULD rows: ULD_ID,Length,Width,Height,Weight_Limit -- ID must start with "U"
    • Package rows: Package_ID,Length,Width,Height,Weight,Type,Delay_Cost -- Type is "Priority" or "Economy"; Delay_Cost is a number for Economy or "-" for Priority
    5000

P-1,55,72,42,18,Priority,-
P-2,40,40,40,9,Economy,142
    Files up to 2 MB. A full run (best-of-5 ensemble + local search + refinement) can take 10-15 minutes for an instance around 400 packages -- this page polls real progress the whole way, it isn't frozen. Smaller instances finish faster.

    Get ARGO for your computer

    Download once, then just open it -- no install, no Python, no server. It runs entirely on your own computer, using your own hardware's full speed.

    Judging on someone else's machine, or want to skip the security prompt entirely? Run any model on your own CSV directly in the browser -- no download, nothing to approve.
    macOS
    Unzip, then right-click the app → Open
    Windows
    Unzip, then run ARGO.exe
    Linux
    Unzip, then run ./ARGO
    First launch may show a security warning since the app isn't code-signed — that's expected, just approve it once.
